# Demo profiles

Для локальной тестовой базы после применения миграций. Скрипт создаёт 15 пользователей
`demo01@example.com` … `demo15@example.com`. Пароль для всех: `DemoPass123!` (в SQL хранится bcrypt-хеш).

На каждого нового пользователя создаются один профиль, одна версия профиля,
одна запись `profile_psycho`, одно фото и 5–6 связей с тегами из общего справочника.
Все имена женские, пол — `female`. Имена, описания, теги и название служебного теста — на русском.
Цели чередуются: общение, отношения, встречи; пол поиска — `all`, возраст поиска — 18–100.
Коды целей в БД (`friendship`, `relationship`, `casual`) сохраняют формат модели;
DTO ленты преобразует их в русские названия. Email и ключи файлов — технические значения.

Показатели Big Five синтетические, в диапазоне 0–1. Служебный тест создаётся только
для внешнего ключа `profile_psycho.test_id`, без вопросов и ответов.
Не назначайте его ID в `CURRENT_TEST_ID`: это не готовый TIPI-тест.

## Запуск из корня репозитория

1. Подготовить фото (в `db/data/cats` должны быть JPG):

   ```sh
   python3 db/seeds/prepare_demo_photos.py
   ```

   Копии получают уникальные имена `demo/profile_01.jpg` … `demo/profile_15.jpg`.
   Изображения могут повторяться. Каталог `db/data` исключён из Git.

2. Запустить SQL в PostgreSQL из Docker Compose:

   ```sh
   docker compose --env-file docker.env exec -T postgres sh -c 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < db/seeds/demo_profiles.sql
   ```

Все вставки выполняются в одной транзакции. Скрипт не удаляет существующие данные.
Повторный запуск пропускает уже существующие demo-email, не меняя их профили или пароли.
Если аккаунт с таким email уже существовал до запуска, он тоже будет пропущен.
В конце выводится таблица количества версий, психологических записей, фото и тегов.

Фото доступны после подключения FileServer `/cats/` к `db/data/cats`.
При запуске backend в Docker этот каталог нужно смонтировать в контейнер.

## TIPI для GET/POST теста

Seed также создаёт отдельный тест `TIPI — Краткий опросник Большой пятёрки (демо)`
и 10 вопросов. Это демонстрационный русский перевод оригинального TIPI,
не валидированная адаптация TIPI-RU.
Источник: [оригинал TIPI](https://gosling.psy.utexas.edu/scales-weve-developed/ten-item-personality-measure-tipi/ten-item-personality-inventory-tipi/).

Тест добавляется даже если все 15 demo-аккаунтов уже существуют. Повторный запуск
не дублирует вопросы и не меняет существующие тексты или ID.

Для локального окружения:

```sh
make local-seed
```

В выводе найдите `CURRENT_TEST_ID=...` либо колонку `current_test_id`.
Укажите этот ID в `local.env` (при запуске API в Docker — в `docker.env`)
и перезапустите API. Не путайте его с отдельным служебным тестом синтетических профилей.

`GET /api/v1/tests/current` вернёт вопросы и шкалу 1–7. В POST передавайте
реальные `question_id` из GET: они не обязаны совпадать с `operation_id`.

Операции: экстраверсия 1/6, доброжелательность 7/2, добросовестность 3/8,
нейротизм 4/9, открытость 5/10 (в каждой паре второй пункт обратный).
Оригинал оценивает эмоциональную устойчивость; приложение хранит противоположный
показатель — нейротизм, поэтому направление пары 4/9 соответствует текущему расчёту.
