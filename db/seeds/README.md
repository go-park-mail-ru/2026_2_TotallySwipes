# Demo profiles

Для локальной тестовой базы после применения миграций. Скрипт создаёт 15 пользователей
`demo01@example.com` … `demo15@example.com`. Пароль для всех: `DemoPass123!` (в SQL хранится bcrypt-хеш).

На каждого нового пользователя создаются один профиль, одна версия профиля,
одна запись `profile_psycho`, одно фото и 5–6 связей с тегами из общего справочника.
Все профили ищут общение, пол поиска — `all`, возраст поиска — 18–100.

Показатели Big Five синтетические, в диапазоне 0–1. Служебный тест создаётся только
для внешнего ключа `profile_psycho.test_id`, без вопросов и ответов.
Не назначайте его ID в `CURRENT_TEST_ID`: это не готовый TIPI-тест.

## Запуск из корня репозитория

1. Подготовить фото (в `db/data/cats` должны быть JPG):

   ```sh
   python3 db/seeds/prepare_demo_photos.py
   ```

   Копии получают уникальные имена `demo/profile_01.jpg` … `demo/profile_15.jpg`.
   Изображения могут повторяться. Каталог `db/data` исключён из Git.

2. Запустить SQL в PostgreSQL из Docker Compose:

   ```sh
   docker compose --env-file docker.env exec -T postgres sh -c 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < db/seeds/demo_profiles.sql
   ```

Все вставки выполняются в одной транзакции. Скрипт не удаляет существующие данные.
Повторный запуск пропускает уже существующие demo-email, не меняя их профили или пароли.
Если аккаунт с таким email уже существовал до запуска, он тоже будет пропущен.
В конце выводится таблица количества версий, психологических записей, фото и тегов.

Фото доступны после подключения FileServer `/cats/` к `db/data/cats`.
При запуске backend в Docker этот каталог нужно смонтировать в контейнер.
