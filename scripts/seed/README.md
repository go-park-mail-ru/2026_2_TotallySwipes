# Demo profiles

Скрипт `scripts/seed/seed_demo.py` создаёт 15 пользователей `demo01@example.com` … `demo15@example.com`
через API, как обычный клиент: регистрация с фото, затем прохождение текущего теста.
Пароль для всех: `DemoPass123!`. В базу и в каталог с фото скрипт напрямую не пишет,
поэтому работает одинаково против локального API, Docker и сервера.

Все имена женские, пол — `female`, пол поиска — `all`, возраст поиска — 18–100.
Цели чередуются, у каждого 5–6 тегов и одно фото. Ответы на тест подобраны так,
чтобы показатели Big Five и совместимость в ленте отличались.

## Запуск

1. Положить JPG, PNG или WebP в `scripts/seed/photos` (содержимое исключено из Git)
   или указать свой каталог через `--photos`. Фото раздаются по кругу и могут повторяться.
2. Запустить API и применить миграции.
3. Из корня репозитория:

   ```sh
   make seed                                  # API на http://localhost:8080
   make seed API=https://api.example.com      # другой адрес
   ```

Повторный запуск пропускает уже существующие email (ответ 409).

## TIPI для GET/POST теста

Тест TIPI и 10 вопросов создаёт миграция `000002_tipi_test` с фиксированным `id = 1`,
сид для этого не нужен. `CURRENT_TEST_ID` по умолчанию равен 1.
Это демонстрационный русский перевод оригинального TIPI,
не валидированная адаптация TIPI-RU.
Источник: [оригинал TIPI](https://gosling.psy.utexas.edu/scales-weve-developed/ten-item-personality-measure-tipi/ten-item-personality-inventory-tipi/).

`GET /api/v1/tests/current` вернёт вопросы и шкалу 1–7. В POST передавайте
реальные `question_id` из GET: они не обязаны совпадать с `operation_id`.

Операции: экстраверсия 1/6, доброжелательность 7/2, добросовестность 3/8,
нейротизм 4/9, открытость 5/10 (в каждой паре второй пункт обратный).
Оригинал оценивает эмоциональную устойчивость; приложение хранит противоположный
показатель — нейротизм, поэтому направление пары 4/9 соответствует текущему расчёту.
