# Интеграционные тесты PostgreSQL

Сюда перенесены прежние `profile_history_test.go` и `filter_feed_test.go`.
Они проверяют историю версий, действительный откат данных, порядок фотографий,
SQL-фильтрацию по полу и возрасту и признак liked_me на настоящем PostgreSQL.
Эти проверки нельзя заменить заранее заданными ответами sqlmock.

Нужна отдельная тестовая база с применёнными миграциями проекта. Тесты создают,
изменяют и удаляют данные; не используйте рабочую базу. Значение
`TEST_HISTORY_DATABASE_URL` должно указывать на тестовую БД.

Из корня проекта:

```sh
go test ./internal/repository/integration_tests -count=1 -v
```

Без `TEST_HISTORY_DATABASE_URL` эти тесты пропускаются. Юнит-тесты в соседней
папке `unit_tests` от этой переменной не зависят.
